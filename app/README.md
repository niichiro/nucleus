# nucleus-app

Кроссплатформенное приложение для телефона и ноутбука, предоставляющее интерфейс управления Nucleus.

> Находится вне основного workspace до Фазы 3 (см. `docs/PLAN.md`).
> Пока на стадии концепта; планируется PWA (Yew/WASM + Web Bluetooth) или Tauri-приложение.

## Планируемые возможности

- Автоматическое обнаружение ближайшего узла Nucleus по BLE / mDNS / Wi-Fi
- Отправка команд (вкл/выкл, яркость, температура) и отображение статуса
- Просмотр логов за выбранный период
- Сценарии и уведомления

## Стек (план)

- **Фреймворк:** Yew (Rust → WASM) или Dioxus
- **Связь:** Web Bluetooth (телефон как BLE-централ), HTTP/WebSocket к `nucleusd`
- **Сборка:** Trunk

## Быстрый старт (ожидается)

```bash
cd app
trunk serve --release
```
